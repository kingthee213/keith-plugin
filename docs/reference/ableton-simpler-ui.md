Slices are created via the Slice By chooser, which has four methods: (1) Transient — slices are placed on the sample's transients automatically; a Sensitivity slider determines how sensitive Simpler is to transient levels and thus how many slices are created; higher numbers = more slices, up to a maximum of 64 slices. (3) Region — slices placed at equal time divisions; the Regions chooser selects the number of evenly-spaced slices (documented as between 2 and 64 segments). (4) Manual — slices created by double-clicking within the sample region; no slices are placed automatically. Slice marker affordances: automatic slices = vertical BLUE lines; manual slices = WHITE.
