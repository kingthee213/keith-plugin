# Vocal samples

Source: `sfzinstruments/legato_vocal_tutorial`, **CC0 1.0** (see LICENSE next to this
file). Sustained vowels only; the repository holds no other vowel with sustains.

Filenames are MIDI note numbers, so a sampler maps them directly.

## Why there is only an Aah

The source has sustained samples for the `a` vowel alone. An "Ooh" would have to be
synthesised by filtering these, which would be inventing a sound and calling it a
recording. It is left out until a verified CC0 source is found.
